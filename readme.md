Neste projeto desenvolvi uma aplicação em Java aplicando os princípios de Programação Orientada a Objetos (POO).

Foram utilizados os pilares:
- Abstração
- Encapsulamento
- Herança
- Polimorfismo

Implementei as classes de domínio conforme o desafio proposto e realizei melhorias como organização do código, separação de responsabilidades e boas práticas de estruturação.

O projeto pode ser executado a partir da classe Main.
